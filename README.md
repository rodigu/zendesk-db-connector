# ZenDBCon (the zendesk to database connector)

leverages ZenPy to connect the Zendesk API and preprocess data to be inserted into a SQL database through pydbcon.

## installation

ZenDBCon is hosted as a package on this repository, and can be installed through pip:

```bash
python -m pip install git+https://github.com/rodigu/zendesk-db-connector -U
```
